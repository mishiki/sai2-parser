PaintTool SAI 2 (.sai2) Parser & PSD/PNG Converter

sai2-parser is an experimental, unofficial open-source parser for files created by SYSTEMAX PaintTool SAI Ver.2.

It can inspect .sai2 files, extract the saved composite image to PNG, and convert supported PaintTool SAI 2 document structure to layered PSD.

Current capabilities

  • Read and inspect PaintTool SAI 2 .sai2 files
  • Convert the saved SAI2 composite image to PNG
  • Convert supported SAI2 layers to PSD
  • Preserve raster layers, folders, masks, blend modes, and clipping groups
  • Decode observed SAI2 linework and vector shapes
  • Preserve unknown layer data for future decoding

About the project

This project exists to support interoperability and long-term preservation of artwork files that users own.

It is not affiliated with or endorsed by SYSTEMAX, and it is not an official PaintTool SAI project. The SAI2 file format is not fully documented, so compatibility is developed incrementally from observed, testable file-format behavior.
