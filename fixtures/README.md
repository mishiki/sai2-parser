# Fixtures

Real artwork and private `.sai2` files must not be committed to this public
repository by default.

Local development may use private fixtures stored elsewhere or copied into
`fixtures/private`; `.gitignore` excludes `*.sai2`. Publishable fixtures should
be small documents created specifically for compatibility testing, contain no
personal artwork, and be accompanied by a note describing how they were created
and what may be redistributed.

Future fixture candidates include simple raster, two-layer, folder, blend,
clipping, mask, large-canvas, text, and linework documents. Where licensing and
privacy permit, an exported reference PNG may accompany a synthetic fixture.
